1. Menu Operations

  • Expand All — Expand all collapsible tree nodes
  • Add Root Menu — Add a new menu item at the root level

2.7.6 Formula Support

Tables support spreadsheet-style formulas powered by HyperFormula (GPL v3). To use a formula, type = followed by the formula expression into a cell. The formula will be evaluated automatically, and the result is displayed in the cell.

A formula bar appears below the toolbar when a table with formulas is active. It shows the cell reference and the formula content of the active cell. You can edit the formula directly in the formula bar.

Tip: Cells containing formulas are highlighted with a light blue background. If a formula has an error, the cell is highlighted in red and the original formula text is shown instead of the error value.

Supported aggregate functions:

SUM, AVERAGE, AVERAGEA, COUNT, COUNTA, MAX, MIN, PRODUCT, STDEV, STDEVP, VAR, VARP, MEDIAN, MODE

Formula examples (with a table that has header columns named "Price", "Quantity", "Total"):

ExampleDescription
=SUM(Price) Sum all values in the "Price" column
=AVERAGE(Price) Average of all values in the "Price" column
=MAX(Price) Maximum value in the "Price" column
=Price * Quantity Multiply values from "Price" and "Quantity" columns in the same row
=SUM(Price1:Price5) Sum a specific range of rows (rows 1 to 5) in the "Price" column
=Price + 10 Add a constant value to the Price column value
=A1 + B1 Reference cells directly by column letter and row number (A=first data column, row number starts at 1)
Note: When using column header names in formulas (e.g., Price), the header name must not contain spaces. Formulas are re-evaluated when any cell value in the table changes. The full HyperFormula function library is available — any standard spreadsheet function can be used.

4. Search

SQLite-based full-text search with OCR support for image text.

4.1 Basic Search

Enter keywords in the search box and click 🔍 Search or press Enter.

4.2 Search Modes

  • Regular Search — Match keywords (with stemming)
  • Regex Search — Enable "Regex" checkbox for pattern matching
  • Global Search — Enable "Global Search" to search all KBs

4.3 Smart Search Syntax (non-Regex Mode)

When the "Regex" checkbox is not checked, the search box supports these formats:

FormatDescriptionExample
xxxx Simple search: match items containing the keyword setup guide → search "setup guide"
aaa | bbb | ccc OR search: match items containing any keyword (| separator) install | config | deploy → match any
aaa bbb ccc or
aaa && bbb && ccc		 AND search: match items containing all keywords (space or && separator) Python install config → all must match
aaa ^ bbb Exclusion search: match items containing aaa but not bbb (^ precedes excluded terms) Python ^ Java → has Python but not Java
Tip: Space-separated words default to AND logic. Use regex mode if you need to search for an exact phrase containing spaces.

4.4 Search Results Panel

Results show KB name, path, and content snippet. Click a result to navigate directly. The panel is resizable by dragging the splitter handle above it.

4.5 Regex Syntax

Supports SQLite regex syntax (X REGEXP Y). Common patterns:

  • ^prefix — Match at start
  • suffix$ — Match at end
  • pat1|pat2 — Match either pattern
  • .* — Match any characters

5. Index System

Automatic indexing of all KB content with incremental updates and OCR support.

5.1 Auto-Indexing

  • New KBs are indexed automatically on server startup
  • Content saves trigger incremental index updates
  • OCR processes images and indexes recognized text

5.2 Manual Rebuild

Run python server.py --force-index to rebuild all indexes. Use --force-index my_kb for a specific KB.

5.3 Index Status

The 📇 Indexing... indicator in the toolbar shows when background indexing is active.

5.4 OCR Text Index

Images in content are processed by PaddleOCR. OCR runs in background processes and does not block the server.

8. Export

The system provides flexible export functionality, supporting PDF, ZIP, and MD formats at two granularity levels.

8.1 Tab-Level Export

Right-click a tab and choose "Export" → select format:

  • PDF — Recursively collects all menu items' content under the current KB and merges them into a single PDF document. Items are indented by depth. Uses NotoSansSC font for CJK character support.
  • ZIP — Directly packages the KB's data folder, including menu.json, content/, images/, and all other files. Unzip and browse as a standalone HTML page.
  • MD — Converts all menu items' content into a single Markdown document. Tables are converted to pipe-table syntax, Mermaid diagrams to ```mermaid fenced code blocks, and images are copied to an images/ folder. If images are present, the output is a ZIP (index.md + images/); otherwise a plain .md file is returned.

8.2 Menu Item-Level Export

Right-click a tree menu item and choose "Export" → select format:

  • PDF — Exports the selected item and all its children into one PDF, arranged by hierarchy depth.
  • ZIP — Generates a standalone HTML page containing the entire subtree content (with inline JSON data), copies referenced images to images/, and packages as a ZIP. Unzip and open index.html to browse offline.
  • MD — Exports the selected item and all its children into a Markdown document. Menu hierarchy is represented by heading levels (depth 0 → ##, depth 1 → ###, etc.). Tables, Mermaid diagrams, and images are handled the same as tab-level MD export.
Tip: PDF export requires pdf_fonts/NotoSansSC-Regular.ttf. If missing, Courier monospace font is used as fallback.
Tip: MD export preserves Mermaid diagram source code as fenced code blocks, which render natively in GitHub, VS Code, Obsidian, and other Markdown viewers that support Mermaid.

9. Knowledge Base Encryption

The system supports password protection for individual knowledge bases (Tabs). Encrypted content is stored on disk using the AES-256-GCM algorithm and cannot be viewed or synced until unlocked.

9.1 Setting a Password

  • Right-click a tab → "Set Password"
  • Enter a password and confirm
  • Once set, all existing content is automatically encrypted, and new content is stored in encrypted form

9.2 Unlocking a Knowledge Base

  • Click an encrypted tab, and the system will automatically prompt for a password
  • Enter the correct password to unlock. You can then view and edit normally within the same browser tab
  • After closing the tab or browser window, you must enter the password again to re-access

9.3 Changing / Removing Password

  • Right-click an unlocked encrypted tab → "Change Password" (requires original password)
  • Right-click an unlocked encrypted tab → "Remove Password" (decrypts all files)

9.4 Important Notes

  • Passwords cannot be recovered — If you forget the password, you will lose access to the knowledge base content
  • Encryption does not affect search indexing — Content can be searched normally once unlocked
  • Encrypted KBs do not support real-time sync — WebSocket synchronization is blocked for security
  • Standalone export is unavailable — Encrypted KBs cannot generate public standalone HTML pages
  • Backups include encrypted files — Encrypted files in the backup ZIP remain encrypted

10. Real-time Sync (WebSocket)

The system uses WebSocket technology to enable real-time collaboration and content synchronization across multiple windows or browsers.

10.1 Multi-window Collaboration

  • Content Sync — Content changes are broadcast to all clients viewing the same document in real-time
  • Menu Sync — Menu structure changes (add, rename, move, delete) are broadcast to all clients viewing the same KB
  • Tab Lifecycle — Tab operations (create, rename, delete) are broadcast to all connected clients

10.2 Document Locking

To prevent concurrent editing conflicts, the system implements a document locking mechanism. When a user starts editing a document, it is locked for other users. The lock is released when the user saves or navigates away.

10.3 Security & Limitations

  • Encrypted KBs — For security reasons, encrypted knowledge bases cannot use real-time sync
  • Connection Status — The system automatically handles connect, disconnect, and room management (join/leave) for tabs and documents

11. Multi-User Management

KBase supports multi-user management, allowing an administrator to manage users and control permissions for different knowledge bases.

11.1 Login & Default Password

  • Open the Settings dialog from the toolbar to log in
  • Default admin password: 1234
  • Once logged in as admin, you can manage users from the Settings panel

11.2 User Roles

RoleDescription
Admin Can create/delete users, create public KBs visible to all users, assign KB owners, and publish bulletin-style content synced in real-time to all logged-in users
Regular User Owns their own KBs, can only see their own KBs plus admin's public KBs. Cannot export or modify admin's KBs

11.3 Creating & Deleting Users

  • Admin can create new users from the Settings panel
  • Deleting a user reassigns all their KBs to admin. The deleted user is immediately logged out in all open windows

11.4 KB Ownership & Permissions

  • Public KBs (created by admin) — visible to all users, editable only by admin
  • Private KBs (created by a user) — owned by that user, visible only to the owner and admin
  • Admin can assign KB ownership to a different user
  • Export permission — Regular users can only export KBs they own. Export menu items for admin-owned KBs are grayed out

11.5 Real-time Sync (Admin Broadcast)

  • When admin edits content in a public KB, changes are synced in real-time to all logged-in users viewing that KB via WebSocket
  • This enables a bulletin-board-style workflow where admin pushes updates to users

当表格中包含公式时，工具栏下方会显示 公式栏，显示当前选中单元格的引用位置和公式内容，你可以在公式栏中直接编辑公式。

提示： 包含公式的单元格会以浅蓝色背景高亮显示。如果公式计算出错，单元格会以红色背景显示，并显示原始公式文本。

支持的聚合函数：

SUM（求和）、AVERAGE（平均值）、COUNT（计数）、MAX（最大值）、MIN（最小值）、PRODUCT（乘积）、MEDIAN（中位数）、MODE（众数）等。

公式示例（假设表头列名为"单价"、"数量"、"总价"）：

示例说明
=SUM(单价) 对"单价"列所有值求和
=AVERAGE(单价) 计算"单价"列的平均值
=MAX(单价) 求"单价"列的最大值
=单价 * 数量 同一行中"单价"乘以"数量"
=SUM(单价1:单价5) 对"单价"列第 1 到第 5 行范围内的值求和
=单价 + 10 将"单价"列的值加上常数 10
=A1 + B1 直接按列字母+行号引用单元格（A 为第一个数据列，行号从 1 开始）
注意： 在公式中使用表头列名（如 单价）时，列名不能包含空格。修改表格中任意单元格的值后，所有公式会自动重新计算。HyperFormula 支持完整的电子表格函数库，任何标准表格函数均可使用。

编辑重命名当前 Tab

关闭隐藏当前 Tab（可在"全部知识库"下拉菜单中重新显示）
删除永久删除 Tab 及其所有数据（需确认）

3.3 拖拽排序

直接 拖拽 Tab 标签可调整知识库的排列顺序：

  • 拖到 Tab 左侧 — 插入到目标 Tab 之前
  • 拖到 Tab 右侧 — 插入到目标 Tab 之后
  • 拖到 Tab 栏空白处 — 排到最后
提示： 拖拽时有蓝色高亮指示放置位置，松开鼠标即完成排序。

3.4 Tab 滚动

当 Tab 过多超出可视区域时，Tab 栏左右两端会出现 ‹ 和 › 滚动按钮。支持：

  • 点击滚动按钮 — 步进滚动
  • 长按滚动按钮 — 连续滚动
  • 鼠标滚轮 — 水平滚动 Tab 栏

3.5 创建新知识库

点击工具栏中的 "新增知识库" 按钮，输入名称创建新的知识库 Tab。创建后会自动建立索引。

3.6 知识库可见性管理

工具栏中的 "全部知识库" 下拉菜单：

  • 勾选/取消勾选单个知识库名称 — 控制该知识库在 Tab 栏的显示/隐藏
  • "全部知识库" 复选框 — 一键显示或隐藏所有知识库
  • 复选框状态：✓（全部可见）/ —（部分可见）/ 空白（全部隐藏）

3.7 阅读位置记忆

系统会自动记录每个 Tab 中最后编辑的菜单项，切换回来时自动恢复阅读位置。

四、搜索功能

搜索功能支持单知识库搜索和全局搜索，以及正则表达式搜索。

4.1 基本搜索

  1. 在工具栏搜索框中输入关键词
  2. 按 Enter 或点击 "🔍 搜索" 按钮执行搜索
  3. 搜索结果显示在底部的搜索结果面板中

4.2 搜索模式

模式说明
当前知识库仅搜索当前 Tab 的内容（默认，不勾选"全局搜索"）
全局搜索勾选 "全局搜索" 复选框，搜索所有可见知识库
正则搜索勾选 "正则" 复选框，使用正则表达式进行高级搜索

4.3 智能搜索语法（非正则模式）

当 "正则" 复选框未勾选时，搜索框支持以下智能语法：

格式说明示例
xxxx 简单搜索：匹配包含该关键词的内容 安装步骤 → 搜索"安装步骤"
aaa | bbb | ccc OR 搜索：匹配包含任意一个关键词的内容（| 分隔） 安装 | 配置 | 部署 → 匹配任一
aaa bbb ccc 或
aaa && bbb && ccc		 AND 搜索：匹配同时包含所有关键词的内容（空格或 && 分隔） Python 安装 配置 → 全部匹配
aaa ^ bbb 排除搜索：匹配包含 aaa 但不包含 bbb 的内容（^ 后面的词被排除） Python ^ Java → 含 Python 但不含 Java
提示： 空格分隔的多个词默认按 AND 逻辑搜索。需要搜索包含空格的精确短语时，请启用正则模式。

4.4 搜索结果面板

  • 结果按 知识库 | 路径 | 内容简述 三列展示
  • 点击结果项自动切换到对应知识库和菜单项
  • 列标题之间的分隔线可 拖拽调整 列宽
  • 点击右上角 ✕ 关闭搜索结果面板
  • 搜索结果面板可通过上边缘的 分割线 拖拽调整高度

4.5 正则表达式语法

启用正则模式后，搜索框中支持：

  • . — 匹配任意单个字符
  • * — 匹配前一个字符 0 次或多次
  • + — 匹配前一个字符 1 次或多次
  • | — 逻辑或（如 abc|def 匹配 abc 或 def）
  • () — 分组
注意： 正则搜索性能低于普通搜索，建议在普通搜索无法满足需求时使用。

五、索引系统

系统使用 SQLite 全文索引引擎，为每个知识库建立独立索引，支持高效的关键词检索。

5.1 自动索引

  • 服务器启动时自动检测新知识库并建立索引
  • 创建新知识库时自动触发索引
  • 保存内容时自动增量更新索引（无需手动操作）

5.2 手动强制重建索引

通过命令行参数 --force-index 强制重建指定（或全部）知识库的索引：

# 重建所有知识库的索引
python server.py --force-index

# 重建指定知识库的索引
python server.py --force-index my_kb_name

5.3 索引状态

  • 索引进行时工具栏会显示 "📇 索引中..." 状态提示
  • 服务器控制台实时显示索引进度：[当前/总数] 项名称

5.4 OCR 文本索引

  • 自动识别内容中的图片文字（使用 PaddleOCR）
  • OCR 识别结果会合并到索引中，实现图片文字搜索
  • 可通过 --disable-ocr 参数关闭 OCR 识别
  • OCR 识别在独立的进程池中并行执行

5.5 索引文件位置

索引数据库存储在 data/db/index_db/ 目录下，每个知识库对应一个 .db 文件。

六、Server.py 命令行

服务器支持丰富的命令行参数，用于配置运行环境。

6.1 基本用法

python server.py [选项]

6.2 完整参数列表

参数默认值说明
--port PORT 9999 服务器监听端口
--data DIR data 数据根目录（存放知识库、数据库等）
--force-index [NAME] — 强制重建索引：指定知识库名称只重建该库；不指定则重建全部
--disable-ocr — 禁用 OCR 图片文字识别功能
--mobile-ocr true|false — 使用轻量级 Mobile OCR 模型（精度较低但内存占用更少）。Windows 上默认启用。使用 --mobile-ocr false 在 Windows 上强制使用服务器模型
--workers-ocr N 8 OCR 工作进程数（每个进程持有一个 PaddleOCR 实例，Windows 上限为 1）
--workers-menu N 8 菜单项索引并行处理数（Windows 上限为 1）
--no-debug — 关闭详细的调试日志（默认开启 debug 日志写入 mybase.log）
--help — 显示帮助信息

6.3 使用示例

# 默认启动（端口 9999）
python server.py

# 指定端口 8080
python server.py --port 8080

# 指定数据目录
python server.py --data /path/to/data

# 启动时强制重建所有索引
python server.py --force-index

# 启动时强制重建指定索引 + 禁用 OCR
python server.py --force-index my_kb --disable-ocr

# 生产环境：指定数据目录 + 减少 OCR 进程
python server.py --data /var/kbdata --workers-ocr 2

6.4 服务器日志

  • 控制台输出 — 实时显示启动信息、索引进度、错误信息
  • 日志文件 — mybase.log，记录详细调试信息（仅在 debug 模式下）和错误信息（始终记录）

6.5 优雅关闭

按 Ctrl + C 可安全关闭服务器，系统会自动：

  • 发送关闭信号给所有工作线程
  • 等待 OCR 进程池清理完成
  • 确保数据完整性

七、使用技巧

7.1 高效编辑

  • 使用 Ctrl + S 经常保存，避免丢失内容
  • 利用"全部知识库"下拉菜单快速切换可见知识库
  • 双击已选中的菜单项直接重命名，无需右键菜单

7.2 数据安全

  • 定期点击 "📦 备份知识库" 按钮打包备份所有数据
  • 备份文件为 ZIP 格式，包含完整的知识库目录结构和内容
  • 可通过 --data 参数将数据目录指向外部存储或备份路径

7.3 搜索技巧

  • 使用 全局搜索 替代逐个切换知识库搜索
  • 启用 正则模式 进行模糊匹配（如 安装|配置 匹配任一关键词）
  • 搜索结果面板的列宽可拖拽调整，方便查看长路径或内容

7.4 性能优化

  • 大型知识库首次启动索引可能需要较长时间，请耐心等待
  • 可通过 --workers-ocr 和 --workers-menu 调整并行度
  • 不需要 OCR 功能时使用 --disable-ocr 可加速启动和保存

7.5 外部帮助文档

  • 直接修改此文件来自定义帮助内容
  • 在 web/ 目录下创建更多 HTML 帮助文档，通过链接引用
  • 添加 web/ 目录下的其他静态资源（图片、样式等）来丰富帮助文档

八、导出功能

系统提供灵活的导出功能，支持将知识库内容导出为 PDF、ZIP 或 MD 格式。

8.1 Tab 级导出

在 Tab 标签上 右键点击，选择「Export」→ 选择格式：

  • PDF — 将当前知识库下所有菜单项的内容递归收集，合并生成一个 PDF 文档。菜单项按深度缩进，使用 NotoSansSC 字体支持中文显示。
  • ZIP — 直接将当前知识库的数据文件夹打包，包含 menu.json、content/、images/ 等所有文件。解压后可作为独立 HTML 页面浏览。
  • MD — 将当前知识库下所有菜单项的内容转换为 Markdown 文档。表格转换为管道表格语法，Mermaid 图表转换为 ```mermaid 代码块，图片复制到 images/ 目录。如果包含图片，输出为 ZIP 包（index.md + images/）；否则直接返回 .md 文件。

8.2 菜单项级导出

在树形菜单项上 右键点击，选择「Export」→ 选择格式：

  • PDF — 导出该菜单项及其所有子项的内容，合并为一个 PDF，按层级深度缩进排列。
  • ZIP — 生成一个独立的 HTML 页面，包含该子树所有内容（内嵌 JSON 数据），并复制引用的图片到 images/ 目录，打包为 ZIP 文件。解压后可直接打开 index.html 浏览。
  • MD — 导出该菜单项及其所有子项为 Markdown 文档。菜单层级通过标题级别表示（depth 0 → ##，depth 1 → ###，依此类推）。表格、Mermaid 图表和图片的处理方式与 Tab 级 MD 导出相同。
提示： PDF 导出需要 pdf_fonts/NotoSansSC-Regular.ttf 字体文件，缺失时自动使用 Courier 等宽字体代替。
提示： MD 导出会保留 Mermaid 图表的源代码作为代码块，在 GitHub、VS Code、Obsidian 等支持 Mermaid 的 Markdown 阅读器中可直接渲染显示。

九、知识库加密

系统支持对 单个知识库（Tab） 设置密码保护，加密后的内容在磁盘上以 AES-256-GCM 算法加密存储，未解锁前无法查看或同步。

9.1 设置密码

  • 在 Tab 标签上 右键 → "设定密码"
  • 输入密码并确认
  • 设置成功后，所有已有内容自动加密，新内容也以加密形式存储

9.2 解锁知识库

  • 点击已加密的 Tab 标签，系统自动弹出密码输入框
  • 输入正确密码后解锁，同一标签页内可正常查看和编辑
  • 关闭标签页或浏览器窗口后，重新打开需要再次输入密码

9.3 修改／解除密码

  • 在已加密的 Tab 上 右键 → "修改密码"（需输入原密码）
  • 在已加密的 Tab 上 右键 → "解除密码"（解密所有文件）

9.4 注意事项

  • 密码无法找回 — 忘记密码后将无法访问该知识库内容
  • 加密不影响搜索索引 — 解锁后可正常搜索
  • 加密知识库不支持实时同步 — WebSocket 同步被阻止，保证数据安全
  • 独立导出不可用 — 加密知识库无法生成公开的独立 HTML 页面
  • 备份包含加密文件 — 备份 ZIP 中的加密文件保持加密状态

十、WebSocket 实时同步

系统采用 WebSocket 技术，支持多窗口或多浏览器之间的实时协作与内容同步。

10.1 多窗口协作

  • 内容同步 — 文档内容的修改会实时广播给所有正在查看该文档的客户端
  • 菜单同步 — 菜单结构的变更（新增、重命名、移动、删除）会实时同步给所有查看该知识库的客户端
  • 标签页生命周期 — 知识库标签页的创建、重命名、删除等操作会广播给所有在线客户端

10.2 文档锁定机制

为防止多人同时编辑同一文档造成冲突，系统引入了文档锁定机制。当一名用户开始编辑文档时，该文档会对其他用户锁定。用户保存内容或离开页面后，锁定会自动解除。

10.3 安全与限制

  • 加密知识库 — 出于安全考虑，已加密的知识库不支持 WebSocket 实时同步
  • 连接管理 — 系统自动处理 WebSocket 的连接、断开以及 Tab/文档的加入与退出管理

十一、多用户管理

KBase 支持多用户管理，管理员可以管理用户账号并控制不同知识库的访问权限。

11.1 登录与默认密码

  • 点击工具栏中的设置按钮打开设置对话框，在设置中登录
  • 默认管理员密码：1234
  • 以管理员身份登录后，即可在设置面板中管理用户

11.2 用户角色

角色说明
Admin（管理员） 可以创建/删除用户、创建对所有用户可见的公共知识库、指定知识库所有者、将编辑内容实时同步到所有在线用户
普通用户 拥有自己创建的知识库，仅可见自己创建的知识库和管理员发布的公共知识库。无法导出或修改管理员的知识库

11.3 创建与删除用户

  • 管理员可以在设置面板中创建新用户
  • 删除用户后，该用户的所有知识库归管理员所有，该用户在所有打开窗口中立即被强制登出

11.4 知识库归属与权限

  • 公共知识库（管理员创建）— 所有用户可见，仅管理员可编辑
  • 私有知识库（普通用户创建）— 归属该用户，仅所有者和管理员可见
  • 管理员可以将知识库所有者变更为其他用户
  • 导出权限 — 普通用户只能导出自己拥有的知识库，管理员拥有的知识库导出菜单项为灰色不可用状态

11.5 实时同步（管理员广播）

  • 管理员在公共知识库中编辑内容时，修改会通过 WebSocket 实时同步给所有正在查看该知识库的登录用户
  • 这实现了公告板式的工作流，管理员可以即时推送更新给用户
