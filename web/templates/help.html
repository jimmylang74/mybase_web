一、菜单窗口操作

左侧菜单窗口（侧边栏）以树形结构组织知识库内容，支持多级嵌套、拖拽排序、自定义样式等功能。

1.1 树形菜单工具栏

侧边栏顶部为 "☰ Menu" 按钮，点击展开下拉菜单：

  • 全部收起 — 折叠所有已展开的树节点
  • 全部展开 — 展开所有可展开的树节点
  • 新增根菜单项 — 在当前知识库根级别添加新菜单项

1.2 右键菜单操作

在任意菜单项上 右键点击 弹出上下文菜单：

功能说明
新增子菜单项在当前项下创建子级菜单
新增菜单项在当前项同级后创建新菜单项
上移将菜单项在同级列表中向上移动一位
下移将菜单项在同级列表中向下移动一位
移动到...弹出目标选择树，将项目移动到指定位置
编辑重命名当前菜单项
定制样式设置图标（Emoji）、字体、字号、颜色、加粗等样式
删除删除当前菜单项及其所有子项（需确认）

1.3 内联重命名

左键 双击 已选中的菜单项，可直接在树中 inline 编辑名称：

  • Enter — 确认保存
  • Esc — 取消编辑

1.4 自定义样式

通过右键 "定制样式" 可为菜单项设置个性化外观：

  • 图标 — 支持 Emoji 字符（如 📁 🔖 ⭐）
  • 字体 / 字号 — 独立于编辑器字体
  • 文字颜色 / 背景颜色 — 自定义配色
  • 加粗 / 下划线 / 删除线 — 文字装饰
提示： 点击 "重置样式" 可一键清除所有自定义样式，恢复默认外观。

1.5 展开与折叠

点击节点左侧的 ▸ / ▾ 箭头切换展开/折叠状态。展开/折叠状态会在切换 Tab 时自动保存。

二、内容窗口编辑与粘贴

右侧内容窗口为富文本编辑器（WYSIWYG），支持丰富的格式化操作。

2.1 编辑器工具栏

控件功能
字体下拉框设置当前文本字体（Arial、宋体、微软雅黑等）
字号下拉框设置文字大小（Small / Normal / Large / X-Large）
B (粗体)切换粗体
I (斜体)切换斜体
U (下划线)切换下划线
S (删除线)切换删除线
颜色（色块▾）设置文字颜色 — 点击色块应用，点击 ▾ 选择颜色
🔗 (链接)插入超链接（URL + 显示文字）
💾 Save手动保存当前内容

2.2 键盘快捷键

  • Ctrl + S — 保存当前编辑的内容
  • Esc — 关闭任意弹出菜单或对话框

2.3 右键上下文菜单

在编辑器中 右键点击 弹出编辑菜单：

  • Bold / Italic / Underline / Strikethrough — 文字格式化
  • Font Family — 设置字体
  • Font Color — 设置文字颜色
  • Remove Format — 清除选中内容的格式
  • Copy / Paste — 复制和粘贴（使用浏览器原生命令）

2.4 粘贴操作

编辑器支持智能粘贴：

  • 粘贴文本 — 纯文本自动插入（不会带入外部格式）
  • 粘贴图片 — 从剪贴板直接粘贴图片（Ctrl+V），图片会自动上传到服务器并插入到光标位置
  • 粘贴富文本 — 保留 HTML 格式内容
提示： 粘贴图片后图片会自动缩放为原尺寸的 50%，并保持宽高比。

2.5 保存机制

  • 编辑器右上角状态栏显示当前编辑状态
  • 内容修改后状态栏显示 "(unsaved)" 标记
  • Tab 名称前出现 "*" 号表示该知识库有未保存内容
  • 切换 Tab 时会自动保存当前内容
  • 保存成功后索引会自动增量更新

2.6 图片操作

  • 粘贴图片 — 从剪贴板直接粘贴（支持 PNG、JPG 等常见格式）
  • 链接点击 — 编辑器中的链接点击后自动在新标签页打开

三、Tab 页面操作

顶部 Tab 栏管理多个知识库页面，支持切换、排序、重命名、隐藏和删除。

3.1 基本操作

  • 左键点击 Tab 名称 — 切换到该知识库
  • 右键点击 Tab 名称 — 弹出 Tab 操作菜单

3.2 Tab 右键菜单

功能说明
编辑重命名当前 Tab
关闭隐藏当前 Tab（可在"全部知识库"下拉菜单中重新显示）
删除永久删除 Tab 及其所有数据（需确认）

3.3 拖拽排序

直接 拖拽 Tab 标签可调整知识库的排列顺序：

  • 拖到 Tab 左侧 — 插入到目标 Tab 之前
  • 拖到 Tab 右侧 — 插入到目标 Tab 之后
  • 拖到 Tab 栏空白处 — 排到最后
提示： 拖拽时有蓝色高亮指示放置位置，松开鼠标即完成排序。

3.4 Tab 滚动

当 Tab 过多超出可视区域时，Tab 栏左右两端会出现 ‹ 和 › 滚动按钮。支持：

  • 点击滚动按钮 — 步进滚动
  • 长按滚动按钮 — 连续滚动
  • 鼠标滚轮 — 水平滚动 Tab 栏

3.5 创建新知识库

点击工具栏中的 "新增知识库" 按钮，输入名称创建新的知识库 Tab。创建后会自动建立索引。

3.6 知识库可见性管理

工具栏中的 "全部知识库" 下拉菜单：

  • 勾选/取消勾选单个知识库名称 — 控制该知识库在 Tab 栏的显示/隐藏
  • "全部知识库" 复选框 — 一键显示或隐藏所有知识库
  • 复选框状态：✓（全部可见）/ —（部分可见）/ 空白（全部隐藏）

3.7 阅读位置记忆

系统会自动记录每个 Tab 中最后编辑的菜单项，切换回来时自动恢复阅读位置。

四、搜索功能

搜索功能支持单知识库搜索和全局搜索，以及正则表达式搜索。

4.1 基本搜索

  1. 在工具栏搜索框中输入关键词
  2. 按 Enter 或点击 "🔍 搜索" 按钮执行搜索
  3. 搜索结果显示在底部的搜索结果面板中

4.2 搜索模式

模式说明
当前知识库仅搜索当前 Tab 的内容（默认，不勾选"全局搜索"）
全局搜索勾选 "全局搜索" 复选框，搜索所有可见知识库
正则搜索勾选 "正则" 复选框，使用正则表达式进行高级搜索

4.3 搜索结果面板

  • 结果按 知识库 | 路径 | 内容简述 三列展示
  • 点击结果项自动切换到对应知识库和菜单项
  • 列标题之间的分隔线可 拖拽调整 列宽
  • 点击右上角 ✕ 关闭搜索结果面板
  • 搜索结果面板可通过上边缘的 分割线 拖拽调整高度

4.4 正则表达式语法

启用正则模式后，搜索框中支持：

  • . — 匹配任意单个字符
  • * — 匹配前一个字符 0 次或多次
  • + — 匹配前一个字符 1 次或多次
  • | — 逻辑或（如 abc|def 匹配 abc 或 def）
  • () — 分组
注意： 正则搜索性能低于普通搜索，建议在普通搜索无法满足需求时使用。

五、索引系统

系统使用 SQLite 全文索引引擎，为每个知识库建立独立索引，支持高效的关键词检索。

5.1 自动索引

  • 服务器启动时自动检测新知识库并建立索引
  • 创建新知识库时自动触发索引
  • 保存内容时自动增量更新索引（无需手动操作）

5.2 手动强制重建索引

通过命令行参数 --force-index 强制重建指定（或全部）知识库的索引：

# 重建所有知识库的索引
python server.py --force-index

# 重建指定知识库的索引
python server.py --force-index my_kb_name

5.3 索引状态

  • 索引进行时工具栏会显示 "📇 索引中..." 状态提示
  • 服务器控制台实时显示索引进度：[当前/总数] 项名称

5.4 OCR 文本索引

  • 自动识别内容中的图片文字（使用 PaddleOCR）
  • OCR 识别结果会合并到索引中，实现图片文字搜索
  • 可通过 --disable-ocr 参数关闭 OCR 识别
  • OCR 识别在独立的进程池中并行执行

5.5 索引文件位置

索引数据库存储在 data/db/index_db/ 目录下，每个知识库对应一个 .db 文件。

六、Server.py 命令行

服务器支持丰富的命令行参数，用于配置运行环境。

6.1 基本用法

python server.py [选项]

6.2 完整参数列表

参数默认值说明
--port PORT 9999 服务器监听端口
--data DIR data 数据根目录（存放知识库、数据库等）
--force-index [NAME] — 强制重建索引：指定知识库名称只重建该库；不指定则重建全部
--disable-ocr — 禁用 OCR 图片文字识别功能
--workers-ocr N 8 OCR 工作进程数（每个进程持有一个 PaddleOCR 实例，Windows 上限为 1）
--workers-menu N 8 菜单项索引并行处理数（Windows 上限为 1）
--no-debug — 关闭详细的调试日志（默认开启 debug 日志写入 mybase.log）
--help — 显示帮助信息

6.3 使用示例

# 默认启动（端口 9999）
python server.py

# 指定端口 8080
python server.py --port 8080

# 指定数据目录
python server.py --data /path/to/data

# 启动时强制重建所有索引
python server.py --force-index

# 启动时强制重建指定索引 + 禁用 OCR
python server.py --force-index my_kb --disable-ocr

# 生产环境：指定数据目录 + 减少 OCR 进程
python server.py --data /var/kbdata --workers-ocr 2

6.4 服务器日志

  • 控制台输出 — 实时显示启动信息、索引进度、错误信息
  • 日志文件 — mybase.log，记录详细调试信息（仅在 debug 模式下）和错误信息（始终记录）

6.5 优雅关闭

按 Ctrl + C 可安全关闭服务器，系统会自动：

  • 发送关闭信号给所有工作线程
  • 等待 OCR 进程池清理完成
  • 确保数据完整性

七、使用技巧

7.1 高效编辑

  • 使用 Ctrl + S 经常保存，避免丢失内容
  • 利用"全部知识库"下拉菜单快速切换可见知识库
  • 双击已选中的菜单项直接重命名，无需右键菜单

7.2 数据安全

  • 定期点击 "📦 备份知识库" 按钮打包备份所有数据
  • 备份文件为 ZIP 格式，包含完整的知识库目录结构和内容
  • 可通过 --data 参数将数据目录指向外部存储或备份路径

7.3 搜索技巧

  • 使用 全局搜索 替代逐个切换知识库搜索
  • 启用 正则模式 进行模糊匹配（如 安装|配置 匹配任一关键词）
  • 搜索结果面板的列宽可拖拽调整，方便查看长路径或内容

7.4 性能优化

  • 大型知识库首次启动索引可能需要较长时间，请耐心等待
  • 可通过 --workers-ocr 和 --workers-menu 调整并行度
  • 不需要 OCR 功能时使用 --disable-ocr 可加速启动和保存
