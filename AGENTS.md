# Project instructions

- Every Git commit message must include a list of the files modified or added by that commit, in addition to the summary. Put the list in the commit message body under a `Files:` section.
- Include every changed file, even when the change is only a version bump or documentation update.

Example commit message body:

```
[feat] Add attachment insertion

Files:
- mybase.py
- web/static/app.js
- web/templates/index.html
```
